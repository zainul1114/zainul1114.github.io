Welcome to Zainul's Engineering Docs

This repository is dedicated to the engineering of high-performance cloud-native infrastructure and AI/ML deployments. We have deeply studied and synthesized advanced practices for managing ephemeral storage, container orchestration, and scalable machine learning pipelines.

  • Kubernetes & OpenShift: Leveraging KinD and Kubespray for cluster administration
  • MLOps Infrastructure: Integrating MLflow, Airflow, Keycloak, and PostgreSQL
  • HPC Workload Scheduling: Slurm and PBS Pro execution on Rocky Linux

Through systematic environment design, container lifecycle management via nerdctl and crictl, and proper hardware evaluation, this documentation teaches you how to build robust, scalable architectures. It helps you design features, manage compute nodes, and automate deployment tasks by laying out explicit rules and system boundaries.
