## About Azilehub Academy

Azilehub Academy provides deep technical learning pathways focused on the intersection of robust DevOps pipelines and scalable MLOps environments. In an era where infrastructure automation meets artificial intelligence, engineers need holistic mastery over container runtimes, monitoring frameworks, and accelerated cluster schedulers.

Our curriculum is built on real-world engineering paradigms. Whether you are establishing local and cloud container architectures via Docker and Kubernetes, setting up metric-driven observability with Prometheus and Grafana, or scaling deep learning models across Slurm and HPC clusters, our tutorials offer step-by-step clarity.

We empower practitioners to master Linux server operating systems, track code via Version Control systems, and build scalable machine learning architectures using PyTorch, Hugging Face, and MLflow.

![About Academy](about-img.png)

> **MISSION:** To equip engineers and system administrators with hands-on, end-to-end expertise across containerized platforms, high-performance workload orchestrators, and production AI stacks to power modern enterprise and research infrastructure.

## Learning Tutorials & Modules

Explore our core engineering tracks:

* **Linux / Git**
  Ubuntu / Debian: standard server operating systems. RHEL / Rocky Linux: enterprise-grade distributions. Systemd: system and service manager. SSH: secure remote access protocol. [[see more]](linux/index.md)
* **Version Control**
  Git: decentralized source code tracking. GitHub / GitLab: cloud hosting and collaboration. Bitbucket: enterprise source control platform. SVN: centralized version control system. [[see more]](version-control/index.md)
* **Containerization**
  Docker: container creation and management. Kubernetes: container orchestration and scaling. Podman: rootless alternative to Docker. Helm: package manager for Kubernetes. [[see more]](containerization/index.md)
* **Monitoring**
  Prometheus: time-series data collection engine. Grafana: metric visualization and dashboards. ELK Stack: log aggregation and analysis. Datadog / Dynatrace: cloud-scale application monitoring. [[see more]](monitoring/index.md)
* **HPC (High-Performance Computing)**
  PBS: Altair PBSPro. Slurm: cluster management and job scheduling. MPI: message passing for parallel computing. Singularity / Apptainer: HPC-optimized container runtimes. Lustre: high-performance parallel file system. [[see more]](hpc/index.md)
* **AI/ML**
  PyTorch / TensorFlow: core deep learning frameworks. Hugging Face: transformer models and datasets. Scikit-learn: machine learning data analysis. MLflow / WandB: experiment tracking and MLOps. [[see more]](ai-ml/index.md)
